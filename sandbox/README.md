# sandbox/ — disposable skill-test output

This directory is **not part of the study**. It holds artifacts generated while exercising the
`.claude/skills/` executable layer end-to-end on a throwaway domain (an event-ticketing platform,
"Tessera"). It exists to smoke-test the skills, not to teach — see `docs/`, `templates/`, `how-to/`,
and `examples/` for the real content.

Everything under `sandbox/event-ticketing/` was produced by running the SDD skills through the
P0→P5 workflow. It is safe to delete. See `sandbox/event-ticketing/TEST-REPORT.md` for the
per-skill findings from the run.
